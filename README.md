# 🤖 AI Chatbot Evaluation Playground

An interactive prototype tool designed to compare and evaluate AI-generated responses across multiple dimensions such as accuracy, tone, bias, and reasoning.

---

## 🧠 Objective

This project explores how different AI systems respond to the same prompt and highlights differences in behavior, consistency, and quality.

---

## ⚙️ How It Works

1. User enters a prompt  
2. Multiple AI-style responses are generated  
3. Each response is evaluated across:
   - Accuracy  
   - Tone  
   - Bias  
   - Reasoning  
4. The system calculates an overall score  
5. Displays the best-performing model  

---

## 📊 Example

**Prompt:**  
"What is the color of silence?"

**Output:**  
ChatGPT → Structured answer  
Gemini → Concise answer  
Claude → Detailed answer  

**Evaluation:**  
- Accuracy: 3–5  
- Tone: 2–5  
- Bias: 3–5  
- Reasoning: 2–5  

---

## 🔍 Key Insight

Different models may produce varying levels of quality even for the same prompt, showing differences in reasoning depth, tone, and reliability.
